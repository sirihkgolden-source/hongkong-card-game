# 香江小風波（hk-roguelite）

> **正式產品名：《香江小風波》**  
> 目錄暫名：`hk-roguelite/`（對外顯示名必須用《香江小風波》）  
> 狀態：垂直切片 Round 2（三角色・一 Act）  
> **這是全新遊戲，不是《香江 Card Game》續作。**

## 產品定位

香港霓虹街頭卡牌 Rogue-lite：揀角色、組牌闖三區，一鋪一個傳奇——短、上癮、想再來一局。

- 世界：香港（街頭／城寨／夜市／天台）
- 本切片：開局三揀一 → 同一 Act1「後巷・夜醒」→ Boss 巷口鐵閘・睇場
- 未做：Act2/3、完整局外商城

## 如何本地打開

```bash
cd hk-roguelite
python3 -m http.server 8766
```

瀏覽器開啟：<http://127.0.0.1:8766/>

**入口檔**：`hk-roguelite/index.html`

## 與舊《香江 Card Game》demo 的隔離

| 規則 | 做法 |
|------|------|
| 新專案路徑 | 本倉庫子目錄 `hk-roguelite/`（產品名《香江小風波》） |
| 新入口 | `hk-roguelite/index.html`（獨立於根目錄 `index.html`） |
| 禁止 | **不修改**倉庫根目錄舊 demo 的主循環／`index.html`／既有遊戲邏輯 |
| 舊作素材 | 僅**複製**進 `hk-roguelite/assets/` 再用於本切片；數值在 `js/data.js` 重表 |
| 禁止搬入 | office_chain／tale_chain、命運年／year_pools／過歲 UI、人生 meta |

## 垂直切片內容（Round 2）

### 三角色（開局可揀）

| 角色 | 被動 | 一句 |
|------|------|------|
| 阿油・後巷經紀 | **快手** | 每第 3 張攻擊 → 下張攻擊 −1 費＋3 傷 |
| 阿珊・茶記夜更 | **檔口** | 每場首次捱打後立刻 **+8 擋** |
| 九哥・招牌霓虹 | **招牌眼** | 每場首次打出技能牌 **抽 1** |

> 名稱取自 PREP_PACK／開案 brief；被動依 Round 2 可見回饋規格。

### 其餘

1. **同一 Act1 地圖 6 節點**：戰鬥 → 戰後三選一 → 短事件「巷口風聲」→ 休息／便利店 → **Boss：巷口鐵閘・睇場**
2. 事件唔發死金幣；小怪勝場有金幣；休息格可花金回血／買牌
3. 戰鬥可輸可贏；死亡結算＋「再來一局」（回選角）
4. **打擊感層**：出牌縮卡→飛軌→落點閃／kickback→傷害上飄；受擊預示＋紅閃；被動橫幅（快手／檔口／眼利）；Boss 戰前強制停一句；單次攻擊總延遲 ≤350ms

預覽請用本機靜態伺服器（見上），瀏覽器需允許音訊（首次點擊後 WebAudio stub 才有 beep）。
