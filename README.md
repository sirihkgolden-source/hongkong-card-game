# 香江 Card Game · 直向切片 Demo（2026-10-24）

可點擊嘅垂直切片：標題 → 今世主頁 → 揀事件 → 編隊（3 張）→ 遇敵 → 自動戰 → 結算。

## 點樣打開

**最穩（推薦）**— 喺本資料夾開本機伺服器：

```bash
cd "/workspace/香江CardGame-試玩demo-lite"
python3 -m http.server 8765
```

然後瀏覽器開：http://127.0.0.1:8765/

**亦可直接雙擊** `index.html`：資料已嵌入 `data.js`，`file://` 一般可用（唔使 fetch）。

## 切片內容

- **人生 run**：第 1–4 年各 4 張事件揀一；結算後年紀＋1，可連續跑
- **出戰卡池**：C01–C10（故事 stub jpg）＋ PASS 美術 **C21–C250**（共 240；預設非舖隊 C241 泥頭車／C244 纜車廂／C248 晨跑徑）；戰鬥卡口袋上限＝統率（max 15，唔跟年）；技能口袋公用全池唔跟年；開戰最多 3
- **技能**：S01–S72；配技槽 4／5／6／7（跟稀有度）；全隊技能 ID 唯一
- **事件**：10 張（後巷／天氣／人情／搵食／舊帳／交通／節慶／打機舖…）；戰／非戰混合
- **敵人**：E01–E04；戰場 3v3

## 戰鬥規則（簡）

- 3v3；回合上限 40
- 出手順序跟「速」；普攻 ≈ 攻；自帶必殺 ≈ 攻×1.5；裝備技橫幅輪轉 ≈ 攻×1.35
- 我方血量 = 位格×20＋40
- 敵全滅勝；我方全滅或回合超限敗；放棄＝敗
- 「快啲」×1／×2／×4；無手動放招；點卡可暫停檢視
