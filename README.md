# 香江 Card Game · 直向切片 Demo（2026-10-24）

可點擊嘅垂直切片：標題 → 今世主頁 → 揀事件 → 編隊（3 張）→ 遇敵 → 自動戰 → 結算。

## 點樣打開

**最穩（推薦）**— 喺本資料夾開本機伺服器：

```bash
cd "/workspace/香江CardGame-試玩demo-lite"
python3 -m http.server 8765
```

然後瀏覽器開：http://127.0.0.1:8765/

**亦可直接雙擊** `index.html`：資料已嵌入 `data.js`，`file://` 一般可用（唔使 fetch）。

## 切片內容

- **人生 run**：第 1–4 年各 4 張事件揀一；結算後年紀＋1，可連續跑
- **出戰卡池**：**243 張**（C01–C253）；預設隊 C241 泥頭車／C244 纜車廂／C248 晨跑徑；戰鬥卡口袋上限＝統率（max 15，唔跟年）；技能口袋公用全池唔跟年；開戰最多 3
- **技能**：S01–S72；配技槽 4／5／6／7（跟稀有度）；全隊技能 ID 唯一
- **事件**：**75 張**（後巷／天氣／人情／搵食／舊帳／交通／節慶／打機舖／商店／送卡／交換卡／升星／故事包分支…）；戰／非戰混合
- **故事包**：6 個全開——初入香江、第一章：九龍城寨風雲、風球未落、手袋三夜、**霓虹未完**（t357）、**打工仔輓歌**（t366）
- **打工仔輓歌（t366）**：香港上班族多分支故事。10 步 × 每步 3 選項＝**59,049 條路徑**；五個結局（成功打工致富／生意失敗／成功買樓成家立室／創業失敗露宿街頭／被詐騙後自殺身亡）。**後果選擇後才揭示**（卡面只寫「後果未知」）；**不設中途獎賞／升級**，只有行到結局才給 **50 膠幣**（一次性）
- **敵人**：E01–E08；**敵方一樣由戰鬥卡池出戰**，可指定主題名單（`enemy.lineup`），數值按年份縮放；戰場 3v3

## 戰鬥規則（簡）

- 3v3；回合上限 40
- 出手順序跟「速」；普攻 ≈ 攻；自帶必殺跟卡牌自帶技能規格（`dmg_mult`／`target`／`power`；群攻、治療、斬殺都會生效）
- 我方血量 = 位格×20＋40
- 敵全滅勝；我方全滅或回合超限敗；放棄＝敗
- 「快啲」×1／×2／×4；無手動放招；點卡可暫停檢視
